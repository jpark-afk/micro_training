Detailed Description

<<cert>> QoS policies supported by a DDS_DomainParticipant entity.

The Qos policy must be set in a consistent manner, DDS_DomainParticipant_set_qos and DDS_DomainParticipantFactory_set_default_participant_qos will fail with DDS_RETCODE_INCONSISTENT_POLICY, and DDS_DomainParticipantFactory_create_participant will fail.

Entity:
DDS_DomainParticipant

QoS Policies and allowed ranges within each Qos.
