Introduction
============

|me| is designed for use in real-time systems and uses
a predictable and deterministic memory manager to ensure that memory growth
is not unbounded, OS memory fragmentation is eliminated and memory usage
can be determined a-priori. The advantage with this design is that proper
operation is ensured as soon as steady state has been reached. However, it
also places an additional burden on the system designer to properly
configure each resource limit. The purpose of this document is to describe
all resource limits in |me|, what the behavioral impact is,
and what the impact on memory usage is.
