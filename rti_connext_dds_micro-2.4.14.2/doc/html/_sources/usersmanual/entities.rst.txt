DDS Entities
============

The main classes extend an abstract base class called a DDS *Entity*. 
Every DDS *Entity* has a set of associated events known as statuses and a 
set of associated Quality of Service Policies (QosPolicies). In addition, 
a *Listener* may be registered with the *Entity* to be called when 
status changes occur. DDS *Entities* may also have attached DDS *Conditions*, 
which provide a way to wait for status changes.

Please note that |rti_me| does not support the following:

- **MultiTopic**
- **ContentFilteredTopic**
- **ReadCondition**
- **QueryConditions**
