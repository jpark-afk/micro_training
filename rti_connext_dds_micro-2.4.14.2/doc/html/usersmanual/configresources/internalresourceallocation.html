4.9.4. Internal Resource Allocation¶

Connext Micro allocates additional resources to entities based on internal needs. As a result, resource limits set by the user will often appear to have increased by a constant when read back. This is because Connext Micro uses additional internal readers and other entities. Connext Micro takes the user-defined value and adds a constant depending on the resource limit, topic and entity being used. For specific values, consult the table below.

See Benchmarks for further details on the amount of memory used by each resource limit in the memory model.
