Gets the singleton instance of the DPSE discovery plugin factory. The singleton instance of the factory is used when creating a domain participant. 

This function gets the single singleton instance of the DPSE discovery plugin factory that is used by the middleware to create a DPSE plugin. In the future, as more discovery plug-\/ins are supported, they will be registered with the middleware by installing different discovery factory instances with the \doxylink{group__DDSDomainParticipantFactoryModule_ga206e77e6b4c2b0db6cefa6ed8d85128d}{DDS\+\_\+\+Domain\+Participant\+Factory}. The singleton instance of the factory is registered with a name, and that name is specified in the \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant} \doxylink{structDDS__DiscoveryQosPolicy}{DDS\+\_\+\+Discovery\+Qos\+Policy}.
