Take a mutex. 

A mutex can only be taken if it is not currently already taken by another thread; it CAN be taken if is it already taken by the same thread. In order to release a mutex, it must be given as many times a it has been taken. Note that {\ttfamily take} will block indefinitely.

Note\+: the mutex is not required to support priority inversion; there is no protection against deadlocks or starvation.
