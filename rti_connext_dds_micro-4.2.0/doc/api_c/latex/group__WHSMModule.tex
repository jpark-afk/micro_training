\doxysubsubsection{Detailed Description}
The WHSM plugin is an implementation of the RTI Connext DDS Micro Writer\+History plugin interface and implements the Data\+Writer writer cache as supported by RTI Connext DDS Micro. RTI Connext DDS Micro requires that a Writer\+History plugin is registered with the name "{}wh"{} in the Domain\+Participant\+Factory before a Data\+Writer can be created. Each instance of a Data\+Writer creates its own instance of the Writer\+History plugin. Please refer to User Manual for an example on how to register the writer history factory.
