{\itshape \doxylink{group__DDSDocGuideModule_a_st_cert}{\texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<}cert\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}}}  Callback to filter a received sample based on serialized data 

When a Data\+Reader receives a (serialized) sample, it will deserialize it before storing it in its queue. On\+\_\+before\+\_\+sample\+\_\+deserialize() is called before deserialization. It allows the application to determine whether or not to drop the sample, before it is read or taken. 

The callback controls whether the sample is filter out of the Data\+Reader\textquotesingle{}s queue, with the sample\+\_\+dropped parameter.
