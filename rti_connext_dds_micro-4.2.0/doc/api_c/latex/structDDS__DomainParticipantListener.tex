This is the interface that can be implemented by an application-\/provided class and then registered with the \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant} such that the application can be notified by RTI Connext DDS Micro of relevant status changes. 

The \doxylink{structDDS__DomainParticipantListener}{DDS\+\_\+\+Domain\+Participant\+Listener} interface extends all other Listener interfaces and has no additional operation beyond the ones defined by the more general listeners. 

The purpose of the \doxylink{structDDS__DomainParticipantListener}{DDS\+\_\+\+Domain\+Participant\+Listener} is to be the listener of last resort that is notified of all status changes not captured by more specific listeners attached to the \doxylink{group__DDSEntityModule_ga0cd8d7d61066e2a434918419e1514bfc}{DDS\+\_\+\+Domain\+Entity} objects. When a relevant status change occurs, RTI Connext DDS Micro will first attempt to notify the listener attached to the concerned \doxylink{group__DDSEntityModule_ga0cd8d7d61066e2a434918419e1514bfc}{DDS\+\_\+\+Domain\+Entity} if one is installed. Otherwise, RTI Connext DDS Micro will notify the Listener attached to the \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant}. 

{\itshape Important\+:} Because a \doxylink{structDDS__DomainParticipantListener}{DDS\+\_\+\+Domain\+Participant\+Listener} may receive callbacks pertaining to many different entities, it is possible for the same listener to receive multiple callbacks simultaneously in different threads. (Such is not the case for listeners of other types.) It is therefore critical that users of this listener provide their own protection for any thread-\/unsafe activities undertaken in a \doxylink{structDDS__DomainParticipantListener}{DDS\+\_\+\+Domain\+Participant\+Listener} callback.
