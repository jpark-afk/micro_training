\hypertarget{structDDS__ReliabilityQosPolicy_DDSReliabilityQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__ReliabilityQosPolicy_DDSReliabilityQosModule_usage}
This policy indicates the level of reliability requested by a \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader} or offered by a \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer}. 

These levels are ordered, \doxylink{group__DDSReliabilityQosModule_ggaf09e82d431c2328186c7fb4b3fa9ad91aae82431f2015239328733f3cb41d780d}{DDS\+\_\+\+BEST\+\_\+\+EFFORT\+\_\+\+RELIABILITY\+\_\+\+QOS} \texorpdfstring{$<$}{<} \doxylink{group__DDSReliabilityQosModule_ggaf09e82d431c2328186c7fb4b3fa9ad91ae5d04022c6405f9db6406489956d1923}{DDS\+\_\+\+RELIABLE\+\_\+\+RELIABILITY\+\_\+\+QOS}. A \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer} offering a level is implicitly offering all levels below. 

If the \doxylink{structDDS__ReliabilityQosPolicy_a94debccb5177400ff7c39a8cb0252c16}{DDS\+\_\+\+Reliability\+Qos\+Policy\+::kind} is set to \doxylink{group__DDSReliabilityQosModule_ggaf09e82d431c2328186c7fb4b3fa9ad91ae5d04022c6405f9db6406489956d1923}{DDS\+\_\+\+RELIABLE\+\_\+\+RELIABILITY\+\_\+\+QOS} , data-\/samples originating from a single \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer} cannot be made available to the \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader} if there are previous data samples that have not been received yet due to a communication error. In other words, the service will repair the error and re-\/transmit data-\/samples as needed in order to reconstruct a correct snapshot of the \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer} history before it is accessible by the \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader}. 

If the \doxylink{structDDS__ReliabilityQosPolicy_a94debccb5177400ff7c39a8cb0252c16}{DDS\+\_\+\+Reliability\+Qos\+Policy\+::kind} is set to \doxylink{group__DDSReliabilityQosModule_ggaf09e82d431c2328186c7fb4b3fa9ad91aae82431f2015239328733f3cb41d780d}{DDS\+\_\+\+BEST\+\_\+\+EFFORT\+\_\+\+RELIABILITY\+\_\+\+QOS}, the service will not re-\/transmit missing data-\/samples. However for data-\/samples originating from any one Data\+Writer the service will ensure they are stored in the \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader} history in the same order they originated in the \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer}. In other words, the \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader} may miss some data samples but it will never see the value of a data-\/object change from a newer value to an older value.

For Readers\+: The maximum time a receive thread may block if the reader is out of resources. For Writers\+: The maximum time a writer may block on a write call. 

For a \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader}\+: A non-\/zero maximum blocking time enables the receive thread to block up to the maximum blocking time if a \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader} is out of resources when new data arrives. This is useful when the \doxylink{structDDS__HistoryQosPolicy_aef0fb3fd3579866be17d1a936f5e3729}{DDS\+\_\+\+History\+Qos\+Policy\+::depth} is equal to {\ttfamily max\+\_\+samples\+\_\+per\+\_\+instance} and the application is using a combination of loans and waitsets or polling. With a value of 0, the receive thread will not block. 

For a \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer}\+: This setting applies only to the case where \doxylink{structDDS__ReliabilityQosPolicy_a94debccb5177400ff7c39a8cb0252c16}{DDS\+\_\+\+Reliability\+Qos\+Policy\+::kind} = \doxylink{group__DDSReliabilityQosModule_ggaf09e82d431c2328186c7fb4b3fa9ad91ae5d04022c6405f9db6406489956d1923}{DDS\+\_\+\+RELIABLE\+\_\+\+RELIABILITY\+\_\+\+QOS}. \doxylink{group__DDSWriterModule_ga2b106f9efd70a4da90b09a7216253aca}{Foo\+Data\+Writer\+\_\+write} is allowed to block if the \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer} does not have space to store the value written.
