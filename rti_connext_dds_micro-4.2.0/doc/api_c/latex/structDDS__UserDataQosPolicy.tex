\hypertarget{structDDS__UserDataQosPolicy_DDSUserDataQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__UserDataQosPolicy_DDSUserDataQosModule_usage}
The USER\+\_\+\+DATA QoS policy allows an application to attach additional information to \doxylink{group__DDSEntityModule_ga928b59d917d674720975f0581149b905}{DDS\+\_\+\+Entity} objects so that when a remote application discovers them, it can access that information and use it for its own purposes. This information is not interpreted by RTI Connext DDS Micro. Use cases are usually application-\/to-\/application identification, authentication, authorization, and encryption. 

The user data for a remote entity is received through the discovery process. The received user data can be accessed through the functions for accessing the discovered entity data\+: \doxylink{group__DDSDomainParticipantModule_gadac59b5a83ac56d364fd2036e4870d81}{DDS\+\_\+\+Domain\+Participant\+\_\+get\+\_\+discovered\+\_\+participant\+\_\+data}, \doxylink{group__DDSWriterModule_ga6a58aff3c0172b335c8ab0fd3bed90b2}{DDS\+\_\+\+Data\+Writer\+\_\+get\+\_\+matched\+\_\+subscription\+\_\+data}, and \doxylink{group__DDSReaderModule_ga40c98d8efe2dd5cba5381fc15820c257}{DDS\+\_\+\+Data\+Reader\+\_\+get\+\_\+matched\+\_\+publication\+\_\+data} operations. 

{\itshape Important\+:} RTI Connext DDS Micro stores the data placed in this policy in pre-\/allocated pools. You must configure RTI Connext DDS Micro with the maximum size and number of the data sequences that will be stored in policies of this type. These settings are configured in the \doxylink{structDDS__DomainParticipantResourceLimitsQosPolicy}{DDS\+\_\+\+Domain\+Participant\+Resource\+Limits\+Qos\+Policy}.
