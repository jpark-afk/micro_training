The maximum number of threads which can block at the same time. 

RTI Connext DDS Micro supports blocking operations, such as \doxylink{group__DDSHistoryQosModule_gga96c54dadb2beb87b23776e766e282185a9e526d876dae232aa083125c72135f5b}{DDS\+\_\+\+KEEP\+\_\+\+ALL\+\_\+\+HISTORY\+\_\+\+QOS}, and may block the user thread in certain conditions, e.\+g. if out of resources. The maximum number of threads that RTI Connext DDS Micro can block at the same time is controlled by this property. 

If a blocking operation is unable to acquire a blocking resource, the operation will return with \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a35b4c98bf40ced0114572156c7f41893}{DDS\+\_\+\+RETCODE\+\_\+\+OUT\+\_\+\+OF\+\_\+\+RESOURCES}. 

Note that receive threads created by a transport and threads calling DDS APIs are both considered user threads. 

{\bfseries{\mbox{[}default\mbox{]}}} 32

The maximum number timers the OS platform support library is required to support. 

RTI Connext DDS Micro implements its own software timers to keep track of Qos polcicies such as \doxylink{structDDS__DeadlineQosPolicy}{DDS\+\_\+\+Deadline\+Qos\+Policy}. These software timers are driven by the underlying platform RTI Connext DDS Micro is executing on. This property configures the maximum number of timers that the OS is required to support. 

RTI Connext DDS Micro allocated uses these timers as follows\+: 

\begin{DoxyItemize}
\item One timer is allocated per \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant} \item One timer is allocated per \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant} for each \doxylink{group__ZCV2Module}{Zero Copy v2 API} transport enabled on a \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant}. \end{DoxyItemize}
The default value supports 8 Domain\+Participants without \doxylink{group__ZCV2Module}{Zero Copy v2 API} enabled and 4 Domain\+Participants with netio\+\_\+zcopy enabled. 

{\bfseries{\mbox{[}default\mbox{]}}} 8
