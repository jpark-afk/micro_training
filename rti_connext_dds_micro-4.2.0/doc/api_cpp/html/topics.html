 USER_DATAThe USER_DATA QoS policy allows the user to attach a buffer of opaque data to a DDSDomainParticipant, DDSDataWriter, or DDSDataReader.  GROUP_DATAThe GROUP_DATA QoS policy allows you to attach a buffer of opaque data to a DDSPublisher or DDSSubscriber.
