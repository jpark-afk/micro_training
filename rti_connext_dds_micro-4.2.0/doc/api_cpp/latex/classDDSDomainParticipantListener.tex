\doxysubsubsection{Detailed Description}
{\itshape \doxylink{group__DDSDocGuideModule_a_st_interface}{\texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<}interface\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}}}  Listener for participant status. 

\begin{DoxyParagraph}{Entity\+:}
\doxylink{classDDSDomainParticipant}{DDSDomain\+Participant} 
\end{DoxyParagraph}
\begin{DoxyParagraph}{Status\+:}
\doxylink{group__DDSStatusTypesModule}{Status Kinds} 
\end{DoxyParagraph}
This is the interface that can be implemented by an application-\/provided class and then registered with the \doxylink{classDDSDomainParticipant}{DDSDomain\+Participant} such that the application can be notified by RTI Connext DDS Micro of relevant status changes. 

The \doxylink{classDDSDomainParticipantListener}{DDSDomain\+Participant\+Listener} interface extends all other Listener interfaces and has no additional operation beyond the ones defined by the more general listeners. 

The purpose of the \doxylink{classDDSDomainParticipantListener}{DDSDomain\+Participant\+Listener} is to be the listener of last resort that is notified of all status changes not captured by more specific listeners attached to the \doxylink{classDDSDomainEntity}{DDSDomain\+Entity} objects. When a relevant status change occurs, RTI Connext DDS Micro will first attempt to notify the listener attached to the concerned \doxylink{classDDSDomainEntity}{DDSDomain\+Entity} if one is installed. Otherwise, RTI Connext DDS Micro will notify the Listener attached to the \doxylink{classDDSDomainParticipant}{DDSDomain\+Participant}. 

{\itshape Important\+:} Because a \doxylink{classDDSDomainParticipantListener}{DDSDomain\+Participant\+Listener} may receive callbacks pertaining to many different entities, it is possible for the same listener to receive multiple callbacks simultaneously in different threads. (Such is not the case for listeners of other types.) It is therefore critical that users of this listener provide their own protection for any thread-\/unsafe activities undertaken in a \doxylink{classDDSDomainParticipantListener}{DDSDomain\+Participant\+Listener} callback.
