\begin{DoxyPrecond}{Precondition}
Certain policies are immutable (see \doxylink{group__DDSQosTypesModule}{QoS Policies})\+: they can only be set at \doxylink{classDDSEntity}{DDSEntity} creation time or before the entity is enabled. If {\ttfamily set\+\_\+qos()} is invoked after the \doxylink{classDDSEntity}{DDSEntity} is enabled and it attempts to change the value of an immutable policy, the operation will fail and return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a6e50f4433cf3e47737f4d317d0a4a707}{DDS\+\_\+\+RETCODE\+\_\+\+IMMUTABLE\+\_\+\+POLICY}. 

Certain values of QoS policies can be incompatible with the settings of the other policies. The {\ttfamily set\+\_\+qos()} operation will also fail if it specifies a set of values that, once combined with the existing values, would result in an inconsistent set of policies. In this case, the operation will fail and return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a5128152d6418ba270e44c5de487ce4c0}{DDS\+\_\+\+RETCODE\+\_\+\+INCONSISTENT\+\_\+\+POLICY}. 

If the application supplies a non-\/default value for a QoS policy that is not supported by the implementation of the service, the set\+\_\+qos operation will fail and return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a9d40db847e4603f57ce3ff0abbd662e7}{DDS\+\_\+\+RETCODE\+\_\+\+UNSUPPORTED}. 
\end{DoxyPrecond}
\begin{DoxyPostcond}{Postcondition}
The existing set of policies is only changed if the {\ttfamily set\+\_\+qos()} operation succeeds. This is indicated by a return code of \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a4f3bc70d86031a38bba356c4b534979f}{DDS\+\_\+\+RETCODE\+\_\+\+OK}. In all other cases, none of the policies are modified. 
\end{DoxyPostcond}

Enables the \doxylink{classDDSEntity}{DDSEntity}. 

This operation enables the Entity. Entity objects can be created either enabled or disabled. This is controlled by the value of the \doxylink{group__DDSEntityFactoryQosModule}{ENTITY\+\_\+\+FACTORY} QoS policy on the corresponding factory for the \doxylink{classDDSEntity}{DDSEntity}. 

By default, \doxylink{group__DDSEntityFactoryQosModule}{ENTITY\+\_\+\+FACTORY} is set so that it is not necessary to explicitly call \doxylink{classDDSEntity_ac8f6cb9f8f0d2eac1daed34b6eb60e11}{DDSEntity\+::enable} on newly created entities. 

The \doxylink{classDDSEntity_ac8f6cb9f8f0d2eac1daed34b6eb60e11}{DDSEntity\+::enable} operation is idempotent. Calling enable on an already enabled Entity returns OK and has no effect. 

If a \doxylink{classDDSEntity}{DDSEntity} has not yet been enabled, the following kinds of operations may be invoked on it\+: 

\begin{DoxyItemize}
\item set or get the QoS policies (including default QoS policies) and listener \item \textquotesingle{}factory\textquotesingle{} operations \item \textquotesingle{}lookup\textquotesingle{} operations \end{DoxyItemize}
Other operations may explicitly state that they may be called on disabled entities; those that do not will return the error \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a2e310a02f1ef7b8a7e5b5f5029b154f9}{DDS\+\_\+\+RETCODE\+\_\+\+NOT\+\_\+\+ENABLED}. 

It is legal to delete an \doxylink{classDDSEntity}{DDSEntity} that has not been enabled by calling the proper operation on its factory. 

Entities created from a factory that is disabled are created disabled, regardless of the setting of the \doxylink{structDDS__EntityFactoryQosPolicy}{DDS\+\_\+\+Entity\+Factory\+Qos\+Policy}. 

Calling enable on an Entity whose factory is not enabled will fail and return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a3a638871d5b4174c32c8d2880f1f6770}{DDS\+\_\+\+RETCODE\+\_\+\+PRECONDITION\+\_\+\+NOT\+\_\+\+MET}. 

If \doxylink{structDDS__EntityFactoryQosPolicy_a4b650acc47f1a51eefd90a072d6a70f6}{DDS\+\_\+\+Entity\+Factory\+Qos\+Policy\+::autoenable\+\_\+created\+\_\+entities} is TRUE, the enable operation on a factory will automatically enable all entities created from that factory. 

Listeners associated with an entity are not called until the entity is enabled.

Retrieves the list of communication statuses in the \doxylink{classDDSEntity}{DDSEntity} that are triggered. 

That is, the list of statuses whose value has changed since the last time the application read the status using the get\+\_\+\texorpdfstring{$\ast$}{*}\+\_\+status() method.

The list of statuses returned by the get\+\_\+status\+\_\+changes operation refers to the status that are triggered on the Entity itself and does not include statuses that apply to contained entities.
