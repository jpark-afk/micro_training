The data structure by which RTI Connext DDS Micro identifies keys in user data types. 

RTI Connext DDS Micro propagates and differentiates between instances of keyed types using \doxylink{group__DDSMicroTypesModule_gac27cb0cd29a0b5eb2655ce5a329dd59f}{DDS\+\_\+\+Instance\+Id\+\_\+t} . Before a sample of a keyed type can be written, its key must be translated into one of these. 

Users who do not edit the code generated by {\ttfamily rtiddsgen} do not need to deal with this type. 

This type is structurally identical to the key type of the built-\/in topic types. A one-\/to-\/one mapping must exist from the key fields of a user data sample to the values of this type\textquotesingle{}s fields.
