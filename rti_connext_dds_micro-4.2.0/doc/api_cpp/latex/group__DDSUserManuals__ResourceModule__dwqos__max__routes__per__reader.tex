\begin{DoxyParagraph}{DESCRIPTION}
Each \doxylink{classDDSDataWriter}{DDSData\+Writer} maintains information about the state of its peer Data\+Readers (those it has matched with). Part of this state is which locators (or destination addresses) it should use to send data to a particular \doxylink{classDDSDataReader}{DDSData\+Reader}. \doxylink{structDDS__DataWriterResourceLimitsQosPolicy_abbf46a75c9cd1bed060b1f1bcf99c66a}{DDS\+\_\+\+Data\+Writer\+Resource\+Limits\+Qos\+Policy\+::max\+\_\+routes\+\_\+per\+\_\+reader} limits the number of routes that can be saved per \doxylink{classDDSDataReader}{DDSData\+Reader}.
\end{DoxyParagraph}
\begin{DoxyParagraph}{NOTES}
This resource-\/limit is shared across all matched Data\+Readers per \doxylink{classDDSDataWriter}{DDSData\+Writer}. One \doxylink{classDDSDataReader}{DDSData\+Reader} may have 6 routes and the other 2.
