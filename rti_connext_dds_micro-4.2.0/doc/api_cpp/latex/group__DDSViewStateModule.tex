Indicates whether or not an instance is new. 

For each instance (identified by the key), the middleware internally maintains a view state relative to each \doxylink{classDDSDataReader}{DDSData\+Reader}. The view state can be either\+: 

\begin{DoxyItemize}
\item \doxylink{group__DDSViewStateModule_ggab7a8a4ae44a2c00f411a4461135b45f1aa16318472ac7f2368d08c969c0e6efef}{DDS\+\_\+\+NEW\+\_\+\+VIEW\+\_\+\+STATE} indicates that either this is the first time that the \doxylink{classDDSDataReader}{DDSData\+Reader} has ever accessed samples of that instance, or else that the \doxylink{classDDSDataReader}{DDSData\+Reader} has accessed previous samples of the instance, but the instance has since been reborn (i.\+e. become not-\/alive and then alive again). \end{DoxyItemize}
\begin{DoxyItemize}
\item \doxylink{group__DDSViewStateModule_ggab7a8a4ae44a2c00f411a4461135b45f1ad0a3502068e5e66e20a873a0aaa881be}{DDS\+\_\+\+NOT\+\_\+\+NEW\+\_\+\+VIEW\+\_\+\+STATE} indicates that the \doxylink{classDDSDataReader}{DDSData\+Reader} has already accessed samples of the same instance and that the instance has not been reborn since. \end{DoxyItemize}
The view\+\_\+state available in the \doxylink{structDDS__SampleInfo}{DDS\+\_\+\+Sample\+Info} is a snapshot of the view state of the instance relative to the \doxylink{classDDSDataReader}{DDSData\+Reader} used to access the samples at the time the collection was obtained (i.\+e. at the time read or take was called). The view\+\_\+state is therefore the same for all samples in the returned collection that refer to the same instance. 

Once an instance has been detected as not having any "{}live"{} writers and all the samples associated with the instance are "{}taken"{} from the \doxylink{classDDSDataReader}{DDSData\+Reader}, the middleware can reclaim all local resources regarding the instance.
