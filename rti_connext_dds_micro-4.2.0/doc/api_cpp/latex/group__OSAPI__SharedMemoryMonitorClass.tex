Acquire the lock protecting the monitor. 

~\newline
 If this function returns RTI\+\_\+\+TRUE, the calling thread is guaranteed mutual exclusion by the monitor. No other thread can acquire the lock until the lock is returned with \doxylink{group__OSAPI__SharedMemoryMonitorClass_gac1118eb2f60fe91bfffdf5635605af62}{OSAPI\+\_\+\+Shared\+Memory\+Monitor\+\_\+release}. This function shall not be called by a thread which currently holds the lock.

If this function returns status\+\_\+out=OSAPI\+\_\+\+SHMEM\+\_\+\+STATUS\+\_\+\+OWNER\+\_\+\+DEAD, then any shared data protected by the monitor may be in an inconsistent state. If the shared data can be restored to a consistent state, then it can be marked as consistent with \doxylink{group__OSAPI__SharedMemoryMonitorClass_ga195fc581005cc9ca601f01546630c7be}{OSAPI\+\_\+\+Shared\+Memory\+Monitor\+\_\+mark\+\_\+consistent}. Otherwise, any subsequent attempts to acquire or wait on the monitor will fail.
