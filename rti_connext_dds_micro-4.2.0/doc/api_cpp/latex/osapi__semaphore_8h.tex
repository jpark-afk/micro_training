Create a Semaphore. 

The created semaphore is a binary semaphore with an initial semaphore value set to 0 and a maximum value of 1. Thus, a call to OSAPI\+\_\+\+Semaphore\+\_\+take will block until the semaphore is signaled with a call to OSAPI\+\_\+\+Semaphore\+\_\+give. 

\begin{DoxyReturn}{Returns}
Pointer to a semaphore with a value of 1 on success, NULL on failure.
