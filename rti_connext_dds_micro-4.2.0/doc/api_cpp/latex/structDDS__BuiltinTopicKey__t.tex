\doxysubsubsection{Detailed Description}
The key type of the built-\/in topic types. 

Each remote \doxylink{classDDSEntity}{DDSEntity} to be discovered can be uniquely identified by this key. This is the key of all the built-\/in topic data types. 

The value of element DDS\+\_\+\+BUILTIN\+\_\+\+TOPIC\+\_\+\+KEY\+\_\+\+OBJECT\+\_\+\+ID is the object ID of the remote entity. In Dynamic Participant/\+Static Endpoint discovery, this must be set correctly for each remote \doxylink{classDDSDataReader}{DDSData\+Reader} and \doxylink{classDDSDataWriter}{DDSData\+Writer} that an application intends to discover. 

For example, to configure a remote \doxylink{classDDSDataWriter}{DDSData\+Writer} with object ID 100 by setting the key in the \doxylink{structDDS__PublicationBuiltinTopicData}{DDS\+\_\+\+Publication\+Builtin\+Topic\+Data}\+:
