Controls if samples can be checked for consistency. 

When this setting is true, the \doxylink{classDDSDataWriter}{DDSData\+Writer} sends an incrementing sequence number as an inline QoS with every sample. This sequence number allows a \doxylink{classDDSDataReader}{DDSData\+Reader} to use the \doxylink{structFooDataReader_ab14ac46cc38d0ff25543a02c0a09fcfb}{Foo\+Data\+Reader\+::is\+\_\+data\+\_\+consistent} API to detect if the \doxylink{classDDSDataWriter}{DDSData\+Writer} overwrote the sample before the \doxylink{classDDSDataReader}{DDSData\+Reader} could complete processing the sample.
