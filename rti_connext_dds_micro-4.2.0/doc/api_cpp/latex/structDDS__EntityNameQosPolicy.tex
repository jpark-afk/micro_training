\hypertarget{structDDS__EntityNameQosPolicy_DDSEntityNameQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__EntityNameQosPolicy_DDSEntityNameQosModule_usage}
The purpose of this QoS is to allow the user to attach naming information to created \doxylink{classDDSEntity}{DDSEntity} objects. 

It can only be 255 characters in length. 

It must be a NULL-\/terminated string allocated with \doxylink{group__DDSStringClass_gaf3b22138dd2db7f1f2a2445d671b9046}{DDS\+\_\+\+String\+\_\+alloc} or \doxylink{group__DDSStringClass_gaab34d3575bf66cd95a890f7e21eb697a}{DDS\+\_\+\+String\+\_\+dup}. 

If the user provides a non-\/\+NULL pointer when getting the QoS, then it should point to valid memory that can be written to, to avoid ungraceful failures.
