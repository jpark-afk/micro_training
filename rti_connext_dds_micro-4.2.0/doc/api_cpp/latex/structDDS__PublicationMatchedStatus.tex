\doxysubsubsection{Detailed Description}

A "{}match"{} happens when the \doxylink{classDDSDataWriter}{DDSData\+Writer} finds a \doxylink{classDDSDataReader}{DDSData\+Reader} for the same \doxylink{classDDSTopic}{DDSTopic} and common partition with a requested QoS that is compatible with that offered by the \doxylink{classDDSDataWriter}{DDSData\+Writer}. 

This status is also changed (and the listener, if any, called) when a match is ended. A local \doxylink{classDDSDataWriter}{DDSData\+Writer} will become "{}unmatched"{} from a remote \doxylink{classDDSDataReader}{DDSData\+Reader} when that \doxylink{classDDSDataReader}{DDSData\+Reader} goes away for any reason.
