\doxysubsubsection{Detailed Description}
\doxylink{group__DDSStatusTypesModule_ggaa99b5585ecdf8c5f93ac3108439ad26faceedf0fda6d695b4fabd8ac0af807bb1}{DDS\+\_\+\+SUBSCRIPTION\+\_\+\+MATCHED\+\_\+\+STATUS} 

A "{}match"{} happens when the \doxylink{classDDSDataReader}{DDSData\+Reader} finds a \doxylink{classDDSDataWriter}{DDSData\+Writer} for the same \doxylink{classDDSTopic}{DDSTopic} with an offered QoS that is compatible with that requested by the \doxylink{classDDSDataReader}{DDSData\+Reader}. 

This status is also changed (and the listener, if any, called) when a match is ended. A local \doxylink{classDDSDataReader}{DDSData\+Reader} will become "{}unmatched"{} from a remote \doxylink{classDDSDataWriter}{DDSData\+Writer} when that \doxylink{classDDSDataWriter}{DDSData\+Writer} goes away for any reason.
