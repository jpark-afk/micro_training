The default Qos policies returned by RTI Connext DDS Micro contain the correctly initialized wire protocol attributes. 

The defaults are not expected to be modified normally, but are available to the advanced user customizing the implementation behavior. 

The default values should not be modified without an understanding of the underlying Real-\/\+Time Publish Subscribe (RTPS) wire protocol.

A value used to distinguish between different participants belonging to the same domain on the same host. 

Determines the unicast port on which meta-\/traffic is received. Also defines the {\itshape default} unicast port for receiving user-\/traffic for Data\+Readers and Data\+Writers . 

For more information on port mapping, please refer to \doxylink{structDDS__RtpsWellKnownPorts__t}{DDS\+\_\+\+Rtps\+Well\+Known\+Ports\+\_\+t}. 

Each \doxylink{classDDSDomainParticipant}{DDSDomain\+Participant} in the same domain, running on the same host, must have a unique {\ttfamily participant\+\_\+id}. The participants may be in the same address space or in distinct address spaces. 

A negative number (-\/1) means that RTI Connext DDS Micro will {\itshape automatically} resolve the participant ID as follows. 

\begin{DoxyItemize}
\item RTI Connext DDS Micro will pick the {\itshape smallest} participant ID, based on the unicast ports available on the transports enabled for discovery. \end{DoxyItemize}
\begin{DoxyItemize}
\item RTI Connext DDS Micro will attempt to resolve an automatic port index either when a Domain\+Partcipant is enabled, or when a Data\+Reader or a Data\+Writer is created. Therefore, all the transports enabled for discovery must have been registered by this time. Otherwise, the discovery transports registered after resolving the automatic port index may produce port conflicts when the Domain\+Partcipant is enabled. \end{DoxyItemize}
{\bfseries{\mbox{[}default\mbox{]}}} -\/1 \mbox{[}automatic\mbox{]}, i.\+e. RTI Connext DDS Micro will automatically pick the {\ttfamily participant\+\_\+id}, as described above. 

{\bfseries{\mbox{[}range\mbox{]}}} \mbox{[}\texorpdfstring{$>$}{>}= 0\mbox{]}, or -\/1, and does not violate guidelines stated in \doxylink{structDDS__RtpsWellKnownPorts__t}{DDS\+\_\+\+Rtps\+Well\+Known\+Ports\+\_\+t}.
