Developing Applications
=======================

This section describes how to write |me| applications. It
covers preparing your development environment, defining data types,
generating support code for your data types, and creating the entities
that publish and subscribe to data.

For a deeper dive into |me|'s features, refer to the 
:ref:`section-users-manual`.
