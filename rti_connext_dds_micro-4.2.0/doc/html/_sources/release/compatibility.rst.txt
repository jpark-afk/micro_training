Compatibility
=============

|me| |version| requires the following minimum versions of |core| products for
compatibility:
 
* |core_pro| 7.3.0 and above [1]_
* *Connext Drive* 3.1.0 and above [1]_

Refer to :ref:`section-micro_and_core` and the :ref:`section-api-reference` for
more details about interoperable APIs, QoS policies, and |core| tools.

.. [1] |me| |version| is not guaranteed to be compatible with all future
       releases of |core| products. Consult the **Downloads** page on
       `support.rti.com <https://support.rti.com/>`__ for up-to-date
       compatibility information.
