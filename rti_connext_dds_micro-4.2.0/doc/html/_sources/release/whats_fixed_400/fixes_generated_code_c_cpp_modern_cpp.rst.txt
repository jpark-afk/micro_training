:critical:`[Critical]` Foo_create_data() failed to create samples for data types with long doubles
--------------------------------------------------------------------------------------------------
``Foo_create_data()`` failed to create samples of types that contained arrays or
sequences of types that contained long doubles. For example, ``Foo_create_data()``
failed for the following type Foo:

.. code-block::

    struct S 
    {
        long double ld;
    };

    struct Foo
    {
        sequence<S> s;
    };

However, ``Foo_create_data()`` did not fail for the following type Foo:

.. code-block::

    struct Foo
    {
        sequence<long double> s;
    };

[RTI Issue ID MICRO-3025]
