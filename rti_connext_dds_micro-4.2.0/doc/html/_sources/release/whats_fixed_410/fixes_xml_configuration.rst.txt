:minor:`[Minor]` Invalid code when using a flow controller
----------------------------------------------------------
*Micro Application Generator* (MAG) generated some invalid code when
using a flow controller in the following scenarios:

-  Trying to use one of the built-in flow controllers.

-  ``SYNCHRONOUS_PUBLISH_MODE_QOS`` was configured.

[RTI Issue ID MAG-174]
