5.1. Connext Micro Platforms¶

Connext Micro includes reference Platform Support Libraries (PSL) as both binaries and source code for the target architectures below. The PSL binaries have been tested and validated by RTI; the included source code is identical to the source code used to build the PSL binaries.

  • Windows®

  • Linux®

  • macOS® (Darwin)

  • QNX®

  • FreeRTOS®

Refer to the Supported Platforms and Programming Languages section for a complete list of all available target architectures.
