Warning

The RTI Connext Micro platform independent libraries are built without the standard C header-files. However, Connext Micro makes one direct call to the C library API qsort. In addition, CLANG may insert direct calls to GLIBC functions and other required functions, such as default C++ constructors and destructors. For this reason, it is necessary to use a CLANG version that is compatible with the CLANG version used to build the platform independent libraries, or provide a C library with an implementation of the required functions. Future versions of RTI Connext Micro will remove these dependencies.
