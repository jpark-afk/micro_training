8.4.9. Interoperability¶

8.4.9.1. [Major] Zero Copy communication failed when applications were started from different directories¶

When two applications were started from different working directories, they would fail to communicate when using the Zero Copy v2 transport.

Note

As a result of this fix, applications using Zero Copy transfer are not backwards compatible with previous versions of Connext Micro.

Refer to the Migration Guide for more information.

[RTI Issue ID MICRO-10391]
