\hypertarget{structDDS__EntityFactoryQosPolicy_DDSEntityFactoryQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__EntityFactoryQosPolicy_DDSEntityFactoryQosModule_usage}
This policy controls the behavior of the \doxylink{group__DDSEntityModule_ga928b59d917d674720975f0581149b905}{DDS\+\_\+\+Entity} as a factory for other entities. 

This policy is mutable. A change in the policy affects only the entities created after the change, not the previously created entities. 

The setting of {\ttfamily autoenable\+\_\+created\+\_\+entities} to \doxylink{group__DDSCdrTypesModule_ga02f257a405ea7ff6774cdf4330a7eeb7}{DDS\+\_\+\+BOOLEAN\+\_\+\+TRUE} indicates that the factory {\ttfamily create\+\_\+$<$entity$>$} operation will automatically invoke the \doxylink{group__DDSEntityModule_ga892fed8d9375b7c3c5f1f610f87e18da}{DDS\+\_\+\+Entity\+\_\+enable} operation each time a new \doxylink{group__DDSEntityModule_ga928b59d917d674720975f0581149b905}{DDS\+\_\+\+Entity} is created. Therefore, the \doxylink{group__DDSEntityModule_ga928b59d917d674720975f0581149b905}{DDS\+\_\+\+Entity} returned by {\ttfamily create\+\_\+$<$entity$>$} will already be enabled. A setting of \doxylink{group__DDSCdrTypesModule_ga727fba6a96485884ccd9438b560689f7}{DDS\+\_\+\+BOOLEAN\+\_\+\+FALSE} indicates that the \doxylink{group__DDSEntityModule_ga928b59d917d674720975f0581149b905}{DDS\+\_\+\+Entity} will not be automatically enabled. The application can enable entities explicitly using the \doxylink{group__DDSEntityModule_ga892fed8d9375b7c3c5f1f610f87e18da}{DDS\+\_\+\+Entity\+\_\+enable} operation. 

By default, {\ttfamily autoenable\+\_\+created\+\_\+entities} is set to \doxylink{group__DDSCdrTypesModule_ga02f257a405ea7ff6774cdf4330a7eeb7}{DDS\+\_\+\+BOOLEAN\+\_\+\+TRUE}, so newly created entities are automatically enabled without needing to call \doxylink{group__DDSEntityModule_ga892fed8d9375b7c3c5f1f610f87e18da}{DDS\+\_\+\+Entity\+\_\+enable}.
