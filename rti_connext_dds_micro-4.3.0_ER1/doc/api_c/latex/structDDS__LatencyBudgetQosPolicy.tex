\doxysubsubsection{Detailed Description}
Provides a hint as to the maximum acceptable delay from the time the data is written to the time it is received by the subscribing applications. 

This policy is a {\itshape hint} to a DDS implementation; it can be used to change how it processes and sends data that has low latency requirements. The DDS specification does not mandate whether or how this policy is used.

\hypertarget{structDDS__LatencyBudgetQosPolicy_DDSLatencyBudgetQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__LatencyBudgetQosPolicy_DDSLatencyBudgetQosModule_usage}
This policy provides a means for the application to indicate to the middleware the urgency of the data communication. By having a non-\/zero {\ttfamily duration}, RTI Connext DDS Micro can optimize its internal operation. 

RTI Connext DDS Micro uses this policy only in conjunction with \doxylink{group__DDSPublishModeQosModule_gga7c71d1e8aba7e852f23c9fcce4b80b42a4ca8021581a2541bb90d19d64fb0ac1e}{DDS\+\_\+\+ASYNCHRONOUS\+\_\+\+PUBLISH\+\_\+\+MODE\+\_\+\+QOS} \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer} instances associated with a \doxylink{group__DDSFlowControllerModule_ggacdd2356baadedf00457c9ce32f5ca115afb77daa170cc951b2387ca9e24003a38}{DDS\+\_\+\+EDF\+\_\+\+FLOW\+\_\+\+CONTROLLER\+\_\+\+SCHED\+\_\+\+POLICY} \doxylink{group__DDSFlowControllerModule_gac250f779038cbaa0e1bde24a4b33db05}{DDS\+\_\+\+Flow\+Controller}. Together with the time of write, \doxylink{structDDS__LatencyBudgetQosPolicy_a28d7a05d6a5559f3e174c5bebe0852b4}{DDS\+\_\+\+Latency\+Budget\+Qos\+Policy\+::duration} determines the deadline of each individual sample. RTI Connext DDS Micro uses this information to prioritize the sending of asynchronously published data. \hypertarget{dds_c_infrastructure.h_DDSLatencyBudgetQosModule_compatibility}{}\doxysubsubsection{\texorpdfstring{Compatibility}{Compatibility}}\label{dds_c_infrastructure.h_DDSLatencyBudgetQosModule_compatibility}
The value offered is considered compatible with the value requested if and only if the inequality {\itshape offered duration \texorpdfstring{$<$}{<}= requested duration} evaluates to \textquotesingle{}TRUE\textquotesingle{}.
