\doxysubsubsection{Detailed Description}
Transformation Rule. 

Defines when and how to apply a transformation to network traffic. 

A rule specifies\+: 

\begin{DoxyItemize}
\item Which addresses to transform (address + netmask) \item Which transformation to apply \item Optional user data to pass to transformation \end{DoxyItemize}
When multiple rules could match, the most specific rule (largest netmask) is selected.
