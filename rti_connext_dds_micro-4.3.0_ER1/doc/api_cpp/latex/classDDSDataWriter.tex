This operation is only useful for keyed data types. Using it for non-\/keyed types causes no effect and returns \doxylink{group__DDSUserDataModule_ga7974338d80c6817f16f77899d908a60e}{DDS\+\_\+\+HANDLE\+\_\+\+NIL}. The operation takes as a parameter an instance (of which only the key value is examined) and returns a {\ttfamily handle} that can be used in successive write() or dispose() operations. 

The operation gives RTI Connext DDS Micro an opportunity to pre-\/configure itself to improve performance. 

The use of this operation by an application is optional even for keyed types. If an instance has not been pre-\/registered, the application can use the special value \doxylink{group__DDSUserDataModule_ga7974338d80c6817f16f77899d908a60e}{DDS\+\_\+\+HANDLE\+\_\+\+NIL} as the \doxylink{group__DDSUserDataModule_ga2cd7a0bbf330870ab93f94e05c92318b}{DDS\+\_\+\+Instance\+Handle\+\_\+t} parameter to the write or dispose operation and RTI Connext DDS Micro will auto-\/register the instance.
