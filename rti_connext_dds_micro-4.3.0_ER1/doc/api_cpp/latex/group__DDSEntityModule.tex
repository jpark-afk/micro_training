\doxysubsubsubsubsection{Detailed Description}
\doxylink{classDDSEntity}{DDSEntity}, \doxylink{classDDSListener}{DDSListener} and related items. 

\doxylink{classDDSEntity}{DDSEntity} subtypes are created and destroyed by factory objects. With the exception of \doxylink{classDDSDomainParticipant}{DDSDomain\+Participant}, whose factory is \doxylink{classDDSDomainParticipantFactory}{DDSDomain\+Participant\+Factory}, all \doxylink{classDDSEntity}{DDSEntity} factory objects are themselves \doxylink{classDDSEntity}{DDSEntity} subtypes as well. 

{\itshape Important\+:} all \doxylink{classDDSEntity}{DDSEntity} delete operations are inherently thread-\/unsafe. The user must take extreme care that a given \doxylink{classDDSEntity}{DDSEntity} is not destroyed in one thread while being used concurrently (including being deleted concurrently) in another thread. An operation\textquotesingle{}s effect in the presence of the concurrent deletion of the operation\textquotesingle{}s target \doxylink{classDDSEntity}{DDSEntity} is undefined.
