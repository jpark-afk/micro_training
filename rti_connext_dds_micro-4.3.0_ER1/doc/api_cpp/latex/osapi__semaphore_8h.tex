Create a Semaphore. 

Create a new binary semaphore with an initial count of 0 and a maximum count of 1. A call to \doxylink{osapi__semaphore_8h_a9f9d0fd812bc225f349c4e5bf0975cc4}{OSAPI\+\_\+\+Semaphore\+\_\+take} will block until the semaphore is signaled with a call to \doxylink{osapi__semaphore_8h_ae739c48b65990c0c12f399af1bc91276}{OSAPI\+\_\+\+Semaphore\+\_\+give}. 

The created semaphore must be deleted using OSAPI\+\_\+\+Semaphore\+\_\+delete when no longer needed (only available when RTI\+\_\+\+CERT is not defined). 

\begin{DoxyReturn}{Returns}
Pointer to a semaphore with an initial count of 0 on success, NULL on failure. 
\end{DoxyReturn}

Take a Semaphore. 

Wait for the semaphore to be signaled. If the semaphore count is greater than 0, this function decrements the count and returns immediately. Otherwise, it blocks until the semaphore is signaled by \doxylink{osapi__semaphore_8h_ae739c48b65990c0c12f399af1bc91276}{OSAPI\+\_\+\+Semaphore\+\_\+give} or the timeout expires.
