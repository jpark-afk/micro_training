Indicate whether a sample should be serialized when it is written (TRUE) or when it is sent (FALSE). 

To send a sample over the network it must first be serialized. The serialize\+\_\+on\+\_\+write attribute determines when the sample is serialized. 

If set to \doxylink{group__DDSCdrTypesModule_ga02f257a405ea7ff6774cdf4330a7eeb7}{DDS\+\_\+\+BOOLEAN\+\_\+\+TRUE}, the sample is serialized when it is written using \doxylink{structFooDataWriter_ab2c44dd15f5daf7eddf3773239101478}{Foo\+Data\+Writer\+::write} or a similar API. This is the default behavior and results in the sample being stored in serialized form in case it needs to be resent. 

If set to \doxylink{group__DDSCdrTypesModule_ga727fba6a96485884ccd9438b560689f7}{DDS\+\_\+\+BOOLEAN\+\_\+\+FALSE}, the sample is not serialized when using \doxylink{structFooDataWriter_ab2c44dd15f5daf7eddf3773239101478}{Foo\+Data\+Writer\+::write} or a similar API. Instead it is serialized when it is needed and never stored in serialized form. This requires the unserialized sample to be available for the life-\/span of the \doxylink{classDDSDataWriter}{DDSData\+Writer}. If this is not the case, this option must not be used. Use of this option will also require a specialized type-\/plugin which is not supported by the IDL compiler.
