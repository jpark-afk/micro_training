\doxysubsubsection{Detailed Description}
Determines the flow control characteristics of the \doxylink{classDDSFlowController}{DDSFlow\+Controller}. 

The flow control characteristics shape the network traffic by determining how often and in what order associated asynchronous \doxylink{classDDSDataWriter}{DDSData\+Writer} instances are serviced and how much data they are allowed to send. 

Note that these settings apply directly to the \doxylink{classDDSFlowController}{DDSFlow\+Controller}, and do not depend on the number of \doxylink{classDDSDataWriter}{DDSData\+Writer} instances the \doxylink{classDDSFlowController}{DDSFlow\+Controller} is servicing. For instance, the specified flow rate does {\itshape not} double simply because two \doxylink{classDDSDataWriter}{DDSData\+Writer} instances are waiting to write.
