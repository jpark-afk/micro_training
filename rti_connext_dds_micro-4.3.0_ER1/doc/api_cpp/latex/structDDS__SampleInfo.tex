\doxysubsubsection{Detailed Description}
Information that accompanies each sample that is {\ttfamily read} or {\ttfamily taken}. 

\hypertarget{structDDS__SampleInfo_Interpretation_SampleInfo}{}\doxysubsubsection{\texorpdfstring{Interpretation of the Sample\+Info}{Interpretation of the Sample\+Info}}\label{structDDS__SampleInfo_Interpretation_SampleInfo}
The \doxylink{structDDS__SampleInfo}{DDS\+\_\+\+Sample\+Info} contains information pertaining to the associated {\ttfamily Data} instance sample including\+: 


\begin{DoxyItemize}
\item the {\ttfamily sample\+\_\+state} of the {\ttfamily Data} value (i.\+e., if it has already been read or not)  


\item the {\ttfamily view\+\_\+state} of the related instance (i.\+e., if the instance is new or not)  


\item the {\ttfamily instance\+\_\+state} of the related instance (i.\+e., if the instance is alive or not)  


\item the {\ttfamily valid\+\_\+data} flag. This flag indicates whether there is data associated with the sample. Some samples do not contain data indicating only a change on the {\ttfamily instance\+\_\+state} of the corresponding instance.  


\item The {\ttfamily source\+\_\+timestamp} of the sample. This is the timestamp provided by the \doxylink{classDDSDataWriter}{DDSData\+Writer} at the time the sample was produced.  
\end{DoxyItemize}

Indicates whether the {\ttfamily Data\+Sample} contains data or else it is only used to communicate a change in the {\ttfamily instance\+\_\+state} of the instance. 

Normally each {\ttfamily Data\+Sample} contains both a \doxylink{structDDS__SampleInfo}{DDS\+\_\+\+Sample\+Info} and some Data. However there are situations where a {\ttfamily Data\+Sample} contains only the \doxylink{structDDS__SampleInfo}{DDS\+\_\+\+Sample\+Info} and does not have any associated data. This occurs when the RTI Connext DDS Micro notifies the application of a change of state for an instance that was caused by some internal mechanism (such as a timeout) for which there is no associated data. An example of this situation is when the RTI Connext DDS Micro detects that an instance has no writers and changes the corresponding instance\+\_\+state to \doxylink{group__DDSInstanceStateModule_ggaf2264cae1aa8cd66490debfdc5e0c360a72ebdc6f53c9a7588458b48e3ea66507}{DDS\+\_\+\+NOT\+\_\+\+ALIVE\+\_\+\+NO\+\_\+\+WRITERS\+\_\+\+INSTANCE\+\_\+\+STATE}. 

The application can distinguish whether a particular {\ttfamily Data\+Sample} has data by examining the value of the {\ttfamily valid\+\_\+data} flag. If this flag is set to \doxylink{group__DDSCdrTypesModule_ga02f257a405ea7ff6774cdf4330a7eeb7}{DDS\+\_\+\+BOOLEAN\+\_\+\+TRUE}, then the {\ttfamily Data\+Sample} contains valid Data. If the flag is set to \doxylink{group__DDSCdrTypesModule_ga727fba6a96485884ccd9438b560689f7}{DDS\+\_\+\+BOOLEAN\+\_\+\+FALSE}, the {\ttfamily Data\+Sample} contains no Data. 

To ensure correctness and portability, the {\ttfamily valid\+\_\+data} flag must be examined by the application prior to accessing the Data associated with the {\ttfamily Data\+Sample} and if the flag is set to \doxylink{group__DDSCdrTypesModule_ga727fba6a96485884ccd9438b560689f7}{DDS\+\_\+\+BOOLEAN\+\_\+\+FALSE}, the application should not access the Data associated with the {\ttfamily Data\+Sample}, that is, the application should access only the \doxylink{structDDS__SampleInfo}{DDS\+\_\+\+Sample\+Info}. \Hypertarget{structDDS__SampleInfo_a70566edcc3c48c0d7ee42962ffb81150}\index{DDS\_SampleInfo@{DDS\_SampleInfo}!source\_timestamp@{source\_timestamp}}

The reception\+\_\+timestamp is platform dependent and depends on the port of RTI Connext DDS Micro to the platform. Typically, it represents the current local time, but that may not always be the case. E.\+g, some platforms may not have a real-\/time clock and the system time is the time since the system was started. 

A reception\+\_\+timestamp equal to zero may mean any of the following\+: \begin{DoxyItemize}
\item RTI Connext DDS Micro was unable to read the current time \item The system time is not incrementing \item Zero time has elapsed between the system was started and the first sample was committed. \end{DoxyItemize}
