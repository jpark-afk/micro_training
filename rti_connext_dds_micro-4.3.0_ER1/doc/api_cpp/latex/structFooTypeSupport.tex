Allows an application to communicate to RTI Connext DDS Micro the existence of a data type. 

The {\itshape generated} implementation of the operation embeds all the knowledge that has to be communicated to the middleware in order to make it able to manage the contents of data of that type. This includes in particular the key definition that will allow RTI Connext DDS Micro to distinguish different instances of the same type. 

The same \doxylink{group__DDSUserDataModule_ga1d7eeb034b2611d4d5f588beea376e22}{DDS\+\_\+\+TYPESUPPORT\+\_\+\+CPP} can be registered multiple times with a \doxylink{classDDSDomainParticipant}{DDSDomain\+Participant} using the same or different values for the {\ttfamily type\+\_\+name}. If {\ttfamily register\+\_\+type} is called multiple times on the same \doxylink{group__DDSUserDataModule_ga1d7eeb034b2611d4d5f588beea376e22}{DDS\+\_\+\+TYPESUPPORT\+\_\+\+CPP} with the same \doxylink{classDDSDomainParticipant}{DDSDomain\+Participant} and {\ttfamily type\+\_\+name}, the second (and subsequent) registrations return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a4f3bc70d86031a38bba356c4b534979f}{DDS\+\_\+\+RETCODE\+\_\+\+OK}. A type must be registered and unregistered an equal number of times. 

\begin{DoxyPrecond}{Precondition}
Cannot use the same {\ttfamily type\+\_\+name} to register two different \doxylink{group__DDSUserDataModule_ga1d7eeb034b2611d4d5f588beea376e22}{DDS\+\_\+\+TYPESUPPORT\+\_\+\+CPP} with the same \doxylink{classDDSDomainParticipant}{DDSDomain\+Participant}, or else the operation will fail and \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a3a638871d5b4174c32c8d2880f1f6770}{DDS\+\_\+\+RETCODE\+\_\+\+PRECONDITION\+\_\+\+NOT\+\_\+\+MET} will be returned.
