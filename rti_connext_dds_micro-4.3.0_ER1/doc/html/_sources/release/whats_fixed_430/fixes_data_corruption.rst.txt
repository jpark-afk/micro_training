Data Corruption
===============

.. Release Notes from this point.

:minor:`[Minor]` DDS_WstringSeq instance could be returned in an inconsistent state when set_maximum failed
-----------------------------------------------------------------------------------------------------------
If the function ``DDS_WstringSeq_set_maximum()`` failed and returned
``RTI_FALSE``, the entire input sequence object could be returned in an
inconsistent state.

[RTI Issue ID MICRO-9999]
