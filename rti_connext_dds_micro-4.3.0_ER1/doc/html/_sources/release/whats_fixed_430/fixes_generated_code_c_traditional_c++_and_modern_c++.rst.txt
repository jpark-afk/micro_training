Generated Code (C, Traditional C++, and Modern C++)
===================================================

.. Release Notes from this point.

:major:`[Major]` Type registration API did not consistently report errors
-------------------------------------------------------------------------
The *DomainParticipant* ``register_type`` API should fail if a data type's
maximum serialized size exceeds 4GB. However, code that was generated with
``interpreted 0`` would not cause the API to fail. Now, type registration
fails consistently for types larger than 4 GB.

[RTI Issue ID MICRO-9889]

:trivial:`[Trivial]` Code Generator did not find Java when run from default directory
-------------------------------------------------------------------------------------
The *rtiddsgen* script could not locate the installed Java Runtime Environment
(JRE) when run directly from the ``bin/`` directory.

[RTI Issue ID MICRO-11600]
