Interoperability
================

.. Release Notes from this point.

:critical:`[Critical]` Failure to ignore vendor-specific PIDS
-------------------------------------------------------------
|me| would not ignore vendor-specific parameter IDs (PIDs)
when deserializing data from other DDS vendors.

[RTI Issue ID MICRO-12271]

:critical:`[Critical]` NULL pointer access in AUTOSAR Classic when a ping message received from |core_pro_h| 7.3.0 or higher
----------------------------------------------------------------------------------------------------------------------------
An AUTOSAR Classic application using |me| caused a NULL pointer access
if a ping message was received from an application using |core_pro| 7.3.0 or
higher.

[RTI Issue ID MICRO-7860]


:major:`[Major]` KeyFlag for fragmented data interpreted incorrectly
--------------------------------------------------------------------
The *KeyFlag* (or K-bit) for fragmented data was interpreted from the wrong
position and was always ignored.

[RTI Issue ID MICRO-11460]
