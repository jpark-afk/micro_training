10.4. What’s Fixed in 4.3.0 ER1¶

The following are fixes since Connext Micro 4.2.0.

[Critical]: System-stopping issue, such as a crash or data loss.
[Major]: Significant issue with no easy workaround.
[Minor]: Issue that usually has a workaround.
[Trivial]: Small issue, such as a typo in a log.

  • 10.4.1. Discovery
    • 10.4.1.1. [Minor] Periodic participant announcements not sent at expected rate
  • 10.4.2. Usability
    • 10.4.2.1. [Major] Network interfaces could not have non-ASCII characters in their name
  • 10.4.3. Transports
    • 10.4.3.1. [Trivial] UDP registration documented incorrectly
    • 10.4.3.2. [Trivial] Internal UDP pings failed to send
  • 10.4.4. Reliability Protocol and Wire Representation
    • 10.4.4.1. [Minor] DataWriter resent already-acknowledged samples when responding to ACKNACK on a lossy network
  • 10.4.5. Callbacks and Waitsets
    • 10.4.5.1. [Minor] DataWriter did not invoke on_offered_incompatible_qos listener when data representations were incompatible
  • 10.4.6. Content Filters and Query Conditions
    • 10.4.6.1. [Major] Possible failure to deliver samples when prior samples were filtered
  • 10.4.7. APIs (C or Traditional C++)
    • 10.4.7.1. [Major] Undefined DDS_TIME_INVALID variables
    • 10.4.7.2. [Major] Setting large max sequence size would produce integer overflow
    • 10.4.7.3. [Minor] Low resolution timestamps could cause Zero Copy samples to remain visible longer than expected
    • 10.4.7.4. [Minor] DDS_Entity_get_entity_kind was declared and documented but not defined
    • 10.4.7.5. [Trivial] False positive error messages when reattaching a condition to a WaitSet
  • 10.4.8. Generated Code (C, Traditional C++, and Modern C++)
    • 10.4.8.1. [Major] Type registration API did not consistently report errors
    • 10.4.8.2. [Trivial] Code Generator did not find Java when run from default directory
  • 10.4.9. Generated Code (Multiple Languages)
    • 10.4.9.1. [Major] Invalid generated code when type was inside modules with duplicate names
  • 10.4.10. OMG Specification Compliance
    • 10.4.10.1. [Minor] DDS_DURATION_INFINITE not compliant with OMG DDS specification
  • 10.4.11. Instances
    • 10.4.11.1. [Minor] Instance state transition inconsistent with Connext Professional
  • 10.4.12. Crashes
    • 10.4.12.1. [Major] Content-filtered DataWriter could crash or fail to send messages
    • 10.4.12.2. [Major] Potential crash from malformed data fragments
  • 10.4.13. Hangs
    • 10.4.13.1. [Critical] Potential deadlock when deleting a DomainParticipant that used the Flow Controller
    • 10.4.13.2. [Major] DataWriters stalled indefinitely when sharing flow controller
  • 10.4.14. Memory Leaks/Growth
    • 10.4.14.1. [Major] Possible memory leaks in CDR_WstringSeq_copy
    • 10.4.14.2. [Major] DDS_DomainParticipantFactory_get_instance() not memory safe on some architectures
    • 10.4.14.3. [Major] Possible memory leak from failed write of a new instance
    • 10.4.14.4. [Minor] Possible memory leak when finalizing Publishers or Subscribers with Partition QoS
    • 10.4.14.5. [Minor] Possible memory leak when Entities experienced errors on topic creation
  • 10.4.15. Data Corruption
    • 10.4.15.1. [Minor] DDS_WstringSeq instance could be returned in an inconsistent state when set_maximum failed
  • 10.4.16. Platform and Build Changes
    • 10.4.16.1. [Major] Possible transmission failure when SocketOwner was configured
    • 10.4.16.2. [Trivial] Not possible to disable thread semaphores
    • 10.4.16.3. [Trivial] rtime-make would not compile Lightweight Security Plugin outside of source directory
  • 10.4.17. Interoperability
    • 10.4.17.1. [Critical] Failure to ignore vendor-specific PIDS
    • 10.4.17.2. [Critical] NULL pointer access in AUTOSAR Classic when a ping message received from Connext Professional 7.3.0 or higher
    • 10.4.17.3. [Major] KeyFlag for fragmented data interpreted incorrectly
  • 10.4.18. Vulnerabilities
    • 10.4.18.1. [Critical] Potential stack buffer underflow in Connext Micro during message processing
    • 10.4.18.2. [Critical] Potential out-of-bounds read in Connext Micro during message processing
    • 10.4.18.3. [Minor] Potential-man-in-the-middle attack in Micro Application Generator when using Socket Appender in Apache Log4j™
  • 10.4.19. Other
    • 10.4.19.1. [Critical] No communication on AUTOSAR systems with multiple IP addresses
    • 10.4.19.2. [Major] DataReader could stop receiving samples due to resource miscount
    • 10.4.19.3. [Minor] Incorrect max size calculation for primitive array with CDR_LONG_DOUBLE_TYPE
    • 10.4.19.4. [Minor] DataWriter silently stopped sending data when flow controller token budget was smaller thanfragment size
    • 10.4.19.5. [Trivial] Possible warning during DomainParticipant shutdown
    • 10.4.19.6. [Trivial] rtime-make and rtiddsgen script errors when running from a directory with a space in its name
    • 10.4.19.7. [Trivial] Formatting errors in help printout for rtime-make.bat
