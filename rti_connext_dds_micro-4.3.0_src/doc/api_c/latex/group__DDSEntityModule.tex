{\itshape \doxylink{group__DDSDocGuideModule_a_st_cert}{\texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<}cert\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}}}  Retrieves the list of communication statuses in the \doxylink{group__DDSEntityModule_ga928b59d917d674720975f0581149b905}{DDS\+\_\+\+Entity} that are triggered. 

That is, the list of statuses whose value has changed since the last time the application read the status using the get\+\_\+\texorpdfstring{$\ast$}{*}\+\_\+status() function. 

When the entity is first created or if the entity is not enabled, all communication statuses are in the "{}untriggered"{} state so the list returned by the get\+\_\+status\+\_\+changes operation will be empty. 

The list of statuses returned by the get\+\_\+status\+\_\+changes operation refers to the statuses that are triggered on the Entity itself and does not include statuses that apply to contained entities.
