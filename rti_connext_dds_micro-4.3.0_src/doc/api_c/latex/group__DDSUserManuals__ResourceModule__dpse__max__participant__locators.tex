A participant locator is defined as a unique index@address to send to where index is an integer \texorpdfstring{$>$}{>}= 0 and only applies to unicast addresses. For multicast address the index is 0. \end{DoxyParagraph}

If memory is limited it is advised to set this value as low as possible.
