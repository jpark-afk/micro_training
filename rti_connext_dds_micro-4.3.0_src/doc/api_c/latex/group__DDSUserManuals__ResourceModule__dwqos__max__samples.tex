\begin{DoxyParagraph}{DESCRIPTION}
\doxylink{structDDS__ResourceLimitsQosPolicy_a90db906a3958146c5e22557db648e7ff}{DDS\+\_\+\+Resource\+Limits\+Qos\+Policy\+::max\+\_\+samples} limits the maximum number of samples a \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer} can allocate and maintain state for at any given time. \end{DoxyParagraph}
