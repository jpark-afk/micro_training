A NETIO interface receives data from a downstream interface. The data can be in different protocol formats. Depending on the downstream protocol different actions may be taken, but semantically it does not matter where data is coming from. The receive interface is synchronous, {\itshape all} processing takes place in the context of the downstream receive context, such as a thread.
