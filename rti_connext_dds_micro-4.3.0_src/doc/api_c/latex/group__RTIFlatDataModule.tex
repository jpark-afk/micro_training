\begin{DoxyWarning}{Warning}
The Flat\+Data language binding is only available in the Traditional C++ API. RTI Connext DDS Micro does not support Modern C++. It is not available in the C API.
\end{DoxyWarning}
Flat\+Data is a language binding for IDL types in which the in-\/memory representation of a sample matches the wire representation. Therefore, the cost of serialization/deserialization is zero.

For a complete description of the Flat\+Data language binding and its benefits, and a tutorial, see the "{}\+Sending Large Data"{} chapter in the {\bfseries{RTI Connext DDS Micro User\textquotesingle{}s Manual}}.
