\hypertarget{structDDS__FilterQosPolicy_DDSFilterQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__FilterQosPolicy_DDSFilterQosModule_usage}
By default if the content filtering feature is enabled, then every \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant} and its child entities will support content filtering. This policy allows the feature or parts of the feature to be disabled for a specific \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant}. 

It is also used to configure the resource limits for all content filters that are created by the child entities of the \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant}. Reducing the resource limits can be useful to reduce the memory usage of the filter, or the limits can be increased to allow for more complex filters to be used. 

A \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader} will fail to be created if it specifies a \doxylink{structDDS__ContentFilterQosPolicy}{DDS\+\_\+\+Content\+Filter\+Qos\+Policy} that is not compatible with the resource limits specified in this policy for its parent \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant}. 

A \doxylink{group__DDSWriterModule_gafb74fa54675abe1bfb2090265bf4d116}{DDS\+\_\+\+Data\+Writer} will be unable to perform writer-\/side filtering for any \doxylink{group__DDSReaderModule_ga49ce0cab2c1b60ddee4784a1432577a4}{DDS\+\_\+\+Data\+Reader} that specifies a content filter that is not compatible with the resource limits specified in this policy for its parent \doxylink{group__DDSDomainParticipantModule_ga1964274885335d5bcea6855f66b0bfe1}{DDS\+\_\+\+Domain\+Participant}.
