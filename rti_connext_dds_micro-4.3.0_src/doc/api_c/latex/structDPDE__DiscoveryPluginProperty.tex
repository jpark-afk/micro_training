The value DDS\+\_\+\+LENGTH\+\_\+\+AUTO calculates the maximum number of locators as Domain\+Participant\+Qos.\+resource\+\_\+limits.\+remote\+\_\+participant\+\_\+allocation + (DPDE\+\_\+\+MAX\+\_\+\+ANON\+\_\+\+PARTICIPANT \texorpdfstring{$\ast$}{*} (initial\+\_\+peers length + 1))

A participant locator is defined as a unique index@address to send to where index is an integer \texorpdfstring{$>$}{>}= 0 and only applies to unicast addresses. For multicast address the index is 0. The maximum number of addresses needed is determined by adding all indices for all unicast addresses and adding one for each multicast address. 

If memory is limited it is advised to set this value as low as possible.
