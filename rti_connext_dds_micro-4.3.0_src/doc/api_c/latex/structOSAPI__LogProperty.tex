Bitmap to control the fidelity of what is stored in the log entry. 

This is an OR-\/combination of \doxylink{group__OSAPILogClass_gaa74109f92b2676734c78a16be4adf010}{OSAPI\+\_\+\+LOG\+\_\+\+DETAIL\+\_\+\+MODULENAME} and related constants into a 32-\/bit bitmap (RTI\+\_\+\+UINT32). Each flag controls whether a specific field is recorded in each \doxylink{structOSAPI__LogEntry}{OSAPI\+\_\+\+Log\+Entry}\+: 

\doxylink{group__OSAPILogClass_gaa74109f92b2676734c78a16be4adf010}{OSAPI\+\_\+\+LOG\+\_\+\+DETAIL\+\_\+\+MODULENAME} — records the module name of the code that logged the entry.

\doxylink{group__OSAPILogClass_ga4829a7f9961f8feac8ef683cb8748a74}{OSAPI\+\_\+\+LOG\+\_\+\+DETAIL\+\_\+\+ALL} — enables all of the above fields combined (the default).
