Detailed Description

Content Filter Interface.

The content filter interface defines the callbacks that must be implemented by a custom content filter class. When a content filter is registered with a DDSDomainParticipant using ::DDSDomainParticipant::register_contentfilter, the filter implementation must provide this interface.
