Callback to filter a received sample based on serialized data 

When a \doxylink{classDDSDataReader}{DDSData\+Reader} receives a (serialized) sample, it will deserialize it before storing it in its queue. On\+\_\+before\+\_\+sample\+\_\+deserialize() is called before deserialization. It allows the application to determine whether or not to drop the sample, before it is read or taken. 

The callback controls whether the sample is filtered out of the Data\+Reader\textquotesingle{}s queue, with the sample\+\_\+dropped parameter. If user code within the callback determines that the sample should be dropped, the user should set sample\+\_\+dropped to true; consequently, when the callback returns, the \doxylink{classDDSDataReader}{DDSData\+Reader} will drop the sample before it is committed to the queue. Otherwise, returning the callback with sample\+\_\+dropped as false will allow the sample to be read or taken. 

Compared to \doxylink{classDDSDataReaderListener_ac645c7898170354c8558b1638a61d2a1}{on\+\_\+before\+\_\+sample\+\_\+commit()}, the sample would be dropped with less processing (without deserialization) by the subscribing application, but with the added complexity of filtering on serialized data. 

The callback is not associated with a DDS Status. Callback to filter a received sample based on deserialized data 

When a \doxylink{classDDSDataReader}{DDSData\+Reader} receives a (serialized) sample, it will deserialize it before storing it in its queue. On\+\_\+before\+\_\+sample\+\_\+commit() is called after deserialization, but before the sample is stored into the Data\+Reader\textquotesingle{}s queue. It allows the application to determine whether or not to drop the sample, before it is read or taken. 

The callback controls whether the sample is filtered out of the Data\+Reader\textquotesingle{}s queue, with the sample\+\_\+dropped parameter. If user code within the callback determines that the sample should be dropped, the user should set sample\+\_\+dropped to true; consequently, when the callback returns, the \doxylink{classDDSDataReader}{DDSData\+Reader} will drop the sample before it is committed to the queue. Otherwise, returning the callback with sample\+\_\+dropped as false will allow the sample to be read or taken. 

Compared to \doxylink{classDDSDataReaderListener_acb80ccd2ba8998cd62b2d544d4b6d480}{on\+\_\+before\+\_\+sample\+\_\+deserialize()}, the sample would be dropped with more processing (with deserialization) by the subscribing application, but with the lesser complexity of filtering on deserialized data. 

The callback is not associated with a DDS Status. It is enabled when the callback in the listener is assigned, to a non-\/\+NULL callback.
