{\itshape \doxylink{group__DDSDocGuideModule_a_st_interface}{\texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<}interface\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}}}  A publisher is the object responsible for the actual dissemination of publications.

A publisher acts on the behalf of one or more \doxylink{classDDSDataWriter}{DDSData\+Writer} objects that belong to it. When it is informed of a change to the data associated with one of its \doxylink{classDDSDataWriter}{DDSData\+Writer} objects, the publisher decides when it is appropriate to actually send the data-\/update message. In making this decision, it considers any extra information that goes with the data (timestamp, writer, etc.) as well as the QoS of the \doxylink{classDDSPublisher}{DDSPublisher} and the \doxylink{classDDSDataWriter}{DDSData\+Writer}. 

The following operations may be called even if the \doxylink{classDDSPublisher}{DDSPublisher} is not enabled. Other operations will fail with the value \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a2e310a02f1ef7b8a7e5b5f5029b154f9}{DDS\+\_\+\+RETCODE\+\_\+\+NOT\+\_\+\+ENABLED} if called on a disabled \doxylink{classDDSPublisher}{DDSPublisher}\+: \begin{DoxyItemize}
