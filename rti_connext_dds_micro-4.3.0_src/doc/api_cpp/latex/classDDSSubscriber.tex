A subscriber acts on the behalf of one or several \doxylink{classDDSDataReader}{DDSData\+Reader} objects that are related to it. When it receives data (from the other parts of the system), it builds the list of concerned \doxylink{classDDSDataReader}{DDSData\+Reader} objects and then indicates to the application that data is available through its listener. 

The application can access the concerned \doxylink{classDDSDataReader}{DDSData\+Reader} objects and then access the data available through operations on the \doxylink{classDDSDataReader}{DDSData\+Reader}. 

The following operations may be called even if the \doxylink{classDDSSubscriber}{DDSSubscriber} is not enabled. Other operations will fail with the value \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a2e310a02f1ef7b8a7e5b5f5029b154f9}{DDS\+\_\+\+RETCODE\+\_\+\+NOT\+\_\+\+ENABLED} if called on a disabled \doxylink{classDDSSubscriber}{DDSSubscriber}\+: \begin{DoxyItemize}
\item The base-\/class operations \doxylink{classDDSEntity_ac8f6cb9f8f0d2eac1daed34b6eb60e11}{DDSEntity\+::enable} \item \doxylink{classDDSSubscriber_adf2acf9e22681064e6966cac2258ac5c}{DDSSubscriber\+::create\+\_\+datareader}  ,\doxylink{classDDSSubscriber_a5dbe420933d7ab3b9d6bf1d2abd6c904}{DDSSubscriber\+::delete\+\_\+datareader}, \doxylink{classDDSSubscriber_a84a62949544b56d16be800aabb795e6b}{DDSSubscriber\+::delete\+\_\+contained\+\_\+entities}.  \end{DoxyItemize}
All operations except for the base-\/class operations \doxylink{classDDSEntity_ac8f6cb9f8f0d2eac1daed34b6eb60e11}{enable()} and \doxylink{classDDSSubscriber_adf2acf9e22681064e6966cac2258ac5c}{create\+\_\+datareader()} may fail with \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a2e310a02f1ef7b8a7e5b5f5029b154f9}{DDS\+\_\+\+RETCODE\+\_\+\+NOT\+\_\+\+ENABLED}.
