A \doxylink{classDDSTopic}{DDSTopic} is identified by its name, which must be unique in the whole domain. In addition (by virtue of extending \doxylink{classDDSTopicDescription}{DDSTopic\+Description}) it fully specifies the type of the data that can be communicated when publishing or subscribing to the \doxylink{classDDSTopic}{DDSTopic}. 

\doxylink{classDDSTopic}{DDSTopic} is the only \doxylink{classDDSTopicDescription}{DDSTopic\+Description} that can be used for publications and therefore associated with a \doxylink{classDDSDataWriter}{DDSData\+Writer}. 

The following operations may be called even if the \doxylink{classDDSTopic}{DDSTopic} is not enabled.
