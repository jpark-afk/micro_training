\doxysubsubsection{Detailed Description}
{\itshape \doxylink{group__DDSDocGuideModule_a_st_interface}{\texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<}interface\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}}} Base class for \doxylink{classDDSTopic}{DDSTopic}. 

\doxylink{classDDSTopicDescription}{DDSTopic\+Description} represents the fact that both publications and subscriptions are tied to a single data-\/type. Its attribute {\ttfamily type\+\_\+name} defines a unique resulting type for the publication or the subscription and therefore creates an implicit association with a type. 

\doxylink{classDDSTopicDescription}{DDSTopic\+Description} has also a {\ttfamily name} that allows it to be retrieved locally.

Get the associated {\ttfamily type\+\_\+name}. 

The type name defines a locally unique type for the publication or the subscription. 

The {\ttfamily type\+\_\+name} corresponds to a unique string used to register a type via the \doxylink{classDDSDomainParticipant_a8b3171bd5b731d936560ba4de4c9887c}{DDSDomain\+Participant\+::register\+\_\+type} method. 

Thus, the {\ttfamily type\+\_\+name} implies an association with a corresponding type and this \doxylink{classDDSTopicDescription}{DDSTopic\+Description}.
