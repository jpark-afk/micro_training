\doxysubsubsubsubsubsection{Detailed Description}
The GROUP\+\_\+\+DATA QoS policy allows you to attach a buffer of opaque data to a \doxylink{classDDSPublisher}{DDSPublisher} or \doxylink{classDDSSubscriber}{DDSSubscriber}. The use of this information is up to user code; RTI Connext DDS Micro distributes this information to other applications as part of the discovery process, but RTI Connext DDS Micro does not interpret the information.
