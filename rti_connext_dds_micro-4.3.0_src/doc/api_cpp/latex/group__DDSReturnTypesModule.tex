\doxysubsubsubsubsection{Detailed Description}
Types of return codes. 

\hypertarget{group__DDSReturnTypesModule_DDSReturnTypesModule_std_retcodes}{}\doxysubsubsubsubsection{\texorpdfstring{Standard Return Codes}{Standard Return Codes}}\label{group__DDSReturnTypesModule_DDSReturnTypesModule_std_retcodes}
Any operation with return type \doxylink{group__DDSReturnTypesModule_ga73f148aaf96b5f6f9fc630b7cfeb0c91}{DDS\+\_\+\+Return\+Code\+\_\+t} may return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a4f3bc70d86031a38bba356c4b534979f}{DDS\+\_\+\+RETCODE\+\_\+\+OK}, \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91ac47a8e813f6e5d652f67dbc551b9f62e}{DDS\+\_\+\+RETCODE\+\_\+\+ERROR} or \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a9abc2fecf5d7348c77744f0b16bdfcf2}{DDS\+\_\+\+RETCODE\+\_\+\+ILLEGAL\+\_\+\+OPERATION}. Any operation that takes one or more input parameters may additionally return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91ad8661c51c31806806aaf10dca3c80f6c}{DDS\+\_\+\+RETCODE\+\_\+\+BAD\+\_\+\+PARAMETER}. Any operation on an object created from any of the factories may additionally return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91adaf7aa0f849422d3e4345bf1c0d98e59}{DDS\+\_\+\+RETCODE\+\_\+\+ALREADY\+\_\+\+DELETED}. Any operation that is stated as optional may additionally return \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a9d40db847e4603f57ce3ff0abbd662e7}{DDS\+\_\+\+RETCODE\+\_\+\+UNSUPPORTED}. 

Thus, the standard return codes are\+: 

\begin{DoxyItemize}
\item \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91ac47a8e813f6e5d652f67dbc551b9f62e}{DDS\+\_\+\+RETCODE\+\_\+\+ERROR} \item \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a9abc2fecf5d7348c77744f0b16bdfcf2}{DDS\+\_\+\+RETCODE\+\_\+\+ILLEGAL\+\_\+\+OPERATION} \item \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91adaf7aa0f849422d3e4345bf1c0d98e59}{DDS\+\_\+\+RETCODE\+\_\+\+ALREADY\+\_\+\+DELETED} \item \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91ad8661c51c31806806aaf10dca3c80f6c}{DDS\+\_\+\+RETCODE\+\_\+\+BAD\+\_\+\+PARAMETER} \item \doxylink{group__DDSReturnTypesModule_gga73f148aaf96b5f6f9fc630b7cfeb0c91a9d40db847e4603f57ce3ff0abbd662e7}{DDS\+\_\+\+RETCODE\+\_\+\+UNSUPPORTED} \end{DoxyItemize}
Operations that may return any of the additional return codes will state so explicitly.
