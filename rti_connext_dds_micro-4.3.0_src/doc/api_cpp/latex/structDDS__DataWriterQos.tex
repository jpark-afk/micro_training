\doxysubsubsection{Detailed Description}
QoS policies supported by a \doxylink{classDDSDataWriter}{DDSData\+Writer} entity. 

The \doxylink{structDDS__DataWriterQos}{DDS\+\_\+\+Data\+Writer\+Qos} controls the resources allocated by a \doxylink{classDDSDataWriter}{DDSData\+Writer}. Each \doxylink{classDDSDataWriter}{DDSData\+Writer} allocates its own resources, even Data\+Writers of the same \doxylink{classDDSTopic}{DDSTopic}. For this reason is it advised to limit the number of Data\+Writers per topic.
