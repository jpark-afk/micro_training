\doxysubsubsection{Detailed Description}
Expresses the maximum duration or deadline within which an instance is expected to be updated. 

\doxylink{classDDSDataReader}{DDSData\+Reader} expects a new sample updating the value of each instance at least once every {\ttfamily period}. \doxylink{classDDSDataWriter}{DDSData\+Writer} indicates that the application commits to write a new value using the \doxylink{classDDSDataWriter}{DDSData\+Writer} for each instance managed by the \doxylink{classDDSDataWriter}{DDSData\+Writer} at least once every {\ttfamily period}. 

If a \doxylink{classDDSDataReader}{DDSData\+Reader} stops receiving samples, it will take at most ({\ttfamily period} + ({\ttfamily period} / 8)) to detect that the deadline has been missed. The deadline period starts again when the next sample is received.

\hypertarget{structDDS__DeadlineQosPolicy_DDSDeadlineQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__DeadlineQosPolicy_DDSDeadlineQosModule_usage}
This policy is useful for cases where a \doxylink{classDDSTopic}{DDSTopic} is expected to have each instance updated periodically. On the publishing side this setting establishes a contract that the application must meet. On the subscribing side the setting establishes a minimum requirement for the remote publishers that are expected to supply the data values. 

When RTI Connext DDS Micro \textquotesingle{}matches\textquotesingle{} a \doxylink{classDDSDataWriter}{DDSData\+Writer} and a \doxylink{classDDSDataReader}{DDSData\+Reader} it checks whether the settings are compatible; that is, {\itshape offered deadline \texorpdfstring{$<$}{<}= requested deadline}; if they are not, the two entities are informed via the \doxylink{classDDSListener}{DDSListener} mechanism of the incompatibility of the QoS settings and communication will not occur. 

Assuming that the reader and writer have compatible settings, the fulfillment of this contract is monitored by RTI Connext DDS Micro and the application is informed of any violations by means of the proper \doxylink{classDDSListener}{DDSListener}. \hypertarget{dds_c_infrastructure.h_DDSDeadlineQosModule_compatibility}{}\doxysubsubsection{\texorpdfstring{Compatibility}{Compatibility}}\label{dds_c_infrastructure.h_DDSDeadlineQosModule_compatibility}
The value offered is considered compatible with the value requested if and only if the inequality {\itshape offered period \texorpdfstring{$<$}{<}= requested period} evaluates to \textquotesingle{}TRUE\textquotesingle{}.
