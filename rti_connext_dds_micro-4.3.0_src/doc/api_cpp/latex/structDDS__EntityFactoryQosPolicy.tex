\hypertarget{structDDS__EntityFactoryQosPolicy_DDSEntityFactoryQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__EntityFactoryQosPolicy_DDSEntityFactoryQosModule_usage}
This policy controls the behavior of the \doxylink{classDDSEntity}{DDSEntity} as a factory for other entities. 

This policy is mutable. A change in the policy affects only the entities created after the change, not the previously created entities. 

The setting of {\ttfamily autoenable\+\_\+created\+\_\+entities} to \doxylink{group__DDSCdrTypesModule_ga02f257a405ea7ff6774cdf4330a7eeb7}{DDS\+\_\+\+BOOLEAN\+\_\+\+TRUE} indicates that the factory {\ttfamily create\+\_\+$<$entity$>$} operation will automatically invoke the \doxylink{classDDSEntity_ac8f6cb9f8f0d2eac1daed34b6eb60e11}{DDSEntity\+::enable} operation each time a new \doxylink{classDDSEntity}{DDSEntity} is created. Therefore, the \doxylink{classDDSEntity}{DDSEntity} returned by {\ttfamily create\+\_\+$<$entity$>$} will already be enabled. A setting of \doxylink{group__DDSCdrTypesModule_ga727fba6a96485884ccd9438b560689f7}{DDS\+\_\+\+BOOLEAN\+\_\+\+FALSE} indicates that the \doxylink{classDDSEntity}{DDSEntity} will not be automatically enabled. The application can enable entities explicitly using the \doxylink{classDDSEntity_ac8f6cb9f8f0d2eac1daed34b6eb60e11}{DDSEntity\+::enable} operation. 

By default, {\ttfamily autoenable\+\_\+created\+\_\+entities} is set to \doxylink{group__DDSCdrTypesModule_ga02f257a405ea7ff6774cdf4330a7eeb7}{DDS\+\_\+\+BOOLEAN\+\_\+\+TRUE}, so newly created entities are automatically enabled without needing to call \doxylink{classDDSEntity_ac8f6cb9f8f0d2eac1daed34b6eb60e11}{DDSEntity\+::enable}.
