\hypertarget{structDDS__EntityNameQosPolicy_DDSEntityNameQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__EntityNameQosPolicy_DDSEntityNameQosModule_usage}
The purpose of this QoS is to allow the user to attach naming information to created \doxylink{classDDSEntity}{DDSEntity} objects. 

The name must not exceed 255 characters in length. 

The name must be a NULL-\/terminated string allocated with \doxylink{group__DDSStringClass_gaf3b22138dd2db7f1f2a2445d671b9046}{DDS\+\_\+\+String\+\_\+alloc} or \doxylink{group__DDSStringClass_gaab34d3575bf66cd95a890f7e21eb697a}{DDS\+\_\+\+String\+\_\+dup}. 

When getting the QoS with a non-\/\+NULL pointer, ensure it points to valid memory. This prevents potential failures. 

Use DDS\+\_\+\+Entity\+Name\+Qos\+Policy\+\_\+set\+\_\+name to set the name.
