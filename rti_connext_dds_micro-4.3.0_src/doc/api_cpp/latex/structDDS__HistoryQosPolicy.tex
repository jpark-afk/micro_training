\doxysubsubsection{Detailed Description}
Specifies the behavior of RTI Connext DDS Micro when a sample value changes one or more times before it can be successfully communicated to existing subscribers. 

This {\ttfamily Qos\+Policy} controls whether RTI Connext DDS Micro should deliver only the most recent value, attempt to deliver all intermediate values, or do something in between. 

On the publishing side this policy controls the samples that should be maintained by the \doxylink{classDDSDataWriter}{DDSData\+Writer} on behalf of existing \doxylink{classDDSDataReader}{DDSData\+Reader} entities. 

On the subscribing side it controls the samples that should be maintained until the application takes them from RTI Connext DDS Micro. 

RTI Connext DDS Micro supports the \doxylink{group__DDSHistoryQosModule_gga96c54dadb2beb87b23776e766e282185a993d3120b7bbb347ce11e0e6f68b29ff}{DDS\+\_\+\+KEEP\+\_\+\+LAST\+\_\+\+HISTORY\+\_\+\+QOS} kind.

\hypertarget{structDDS__HistoryQosPolicy_DDSHistoryQosModule_usage}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{structDDS__HistoryQosPolicy_DDSHistoryQosModule_usage}
This policy controls the behavior of RTI Connext DDS Micro when an instance value changes before it is communicated to its existing \doxylink{classDDSDataReader}{DDSData\+Reader} entities. 

When the kind is set to \doxylink{group__DDSHistoryQosModule_gga96c54dadb2beb87b23776e766e282185a993d3120b7bbb347ce11e0e6f68b29ff}{DDS\+\_\+\+KEEP\+\_\+\+LAST\+\_\+\+HISTORY\+\_\+\+QOS}, RTI Connext DDS Micro will only keep the latest values of the instance and discard older ones. The value of {\ttfamily depth} regulates the maximum number of values that RTI Connext DDS Micro will maintain and deliver. The default for depth is 1, which means only the most recent value is delivered. \hypertarget{dds_c_infrastructure.h_DDSHistoryQosModule_consistency}{}\doxysubsubsection{\texorpdfstring{Consistency}{Consistency}}\label{dds_c_infrastructure.h_DDSHistoryQosModule_consistency}
The {\ttfamily depth} setting must be consistent with the \doxylink{group__DDSResourceLimitsQosModule}{RESOURCE\+\_\+\+LIMITS} {\ttfamily max\+\_\+samples\+\_\+per\+\_\+instance} setting. This requires the following constraint\+: {\itshape depth \texorpdfstring{$<$}{<}= max\+\_\+samples\+\_\+per\+\_\+instance}.
