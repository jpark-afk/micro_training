.. warning::

  The |rti_me| platform independent libraries are built without the standard C
  header-files. However, |me| makes one direct call to
  the C library API ``qsort``. In addition, QCC may insert direct calls
  to GLIBC functions and other required functions, such as default C++
  constructors and destructors. For this reason, it is necessary to use a
  QCC version that is compatible with the QCC version used to build the
  platform independent libraries, or provide a C library with an implementation
  of the required functions. Future versions of |rti_me| will remove these
  dependencies.
