.. Release Notes from this point.

:major:`[Major]` Network interfaces could not have non-ASCII characters in their name
-------------------------------------------------------------------------------------
If any of the adapter names contained one or more non-ASCII characters in a
Windows system, creating associated *DomainParticipants* failed and returned
``ModuleID=7 Errcode=813  X = 1 E = 0 T = 1``.

[RTI Issue ID MICRO-11127]
