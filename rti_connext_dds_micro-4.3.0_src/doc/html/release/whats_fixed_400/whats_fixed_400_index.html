10.5.8. What’s Fixed in 4.0.0¶

The following are fixes since Connext Micro 3.0.3.

[Critical]: System-stopping issue, such as a crash or data loss.
[Major]: Significant issue with no easy workaround.
[Minor]: Issue that usually has a workaround.
[Trivial]: Small issue, such as a typo in a log.

  • 10.5.8.1. Discovery
    • 10.5.8.1.1. [Critical] Failure to interoperate with other DDS implementations if default multicast locator specified
    • 10.5.8.1.2. [Major] Incorrect lease_duration may have been used for a discovered participant.
  • 10.5.8.2. Serialization and Deserialization
    • 10.5.8.2.1. [Critical] DataReader on a Topic using an appendable type may receive samples with incorrect value
    • 10.5.8.2.2. [Critical] Malformed samples with invalid strings not dropped by DataReader
    • 10.5.8.2.3. [Major] Float and double ranges may not have been enforced correctly
    • 10.5.8.2.4. [Major] Deserialization of tampered/corrupted samples may have unexpectedly succeeded
    • 10.5.8.2.5. [Major] Invalid serialization of samples with types containing nested structures with primitive members that require padding
    • 10.5.8.2.6. [Minor] Serialization of string members did not check for null-terminated strings in C, traditional C++, and modern C++
  • 10.5.8.3. Usability
    • 10.5.8.3.1. [Trivial] Thread names were not set on QNX
  • 10.5.8.4. Transports
    • 10.5.8.4.1. [Critical] Stalled communication when using shared-memory transport
    • 10.5.8.4.2. [Critical] Undefined behavior when using SHMEM transport in Linux, macOS, QNX, Integrity, and Lynx
  • 10.5.8.5. Reliability Protocol and Wire Representation
    • 10.5.8.5.1. [Critical] Reliable DataWriter may have ignored requests to resend samples
    • 10.5.8.5.2. [Minor] Incorrect heartbeat sent before first sample when first_write_sequence_number is different from 1
  • 10.5.8.6. Logging
    • 10.5.8.6.1. [Major] Race condition and memory corruption in logger
  • 10.5.8.7. Performance and Scalability
    • 10.5.8.7.1. [Trivial] Asynchronous publication delay
  • 10.5.8.8. APIs (C or Traditional C++)
    • 10.5.8.8.1. [Critical] Segmentation fault when finalizing DataWriter QoS
    • 10.5.8.8.2. [Major] DDS_Subscriber_lookup_datareader may return a DataReader that was created by a different Subscriber
    • 10.5.8.8.3. [Major] DDS_Publisher_lookup_datawriter may return a DataWriter that was created by a different Publisher
    • 10.5.8.8.4. [Major] DDS_Entity_enable was not thread-safe for a DomainParticipant
    • 10.5.8.8.5. [Major] Race condition in DDS enable APIs
    • 10.5.8.8.6. [Minor] DDS_FLOW_CONTROLLER_PROPERTY_DEFAULT ignored when used as argument to DDS_DomainParticipant_create_flowcontroller
    • 10.5.8.8.7. [Minor] Failure to parse invalid index
  • 10.5.8.9. Generated Code (C, Traditional C++, and Modern C++)
    • 10.5.8.9.1. [Critical] Foo_create_data() failed to create samples for data types with long doubles
    • 10.5.8.9.2. [Minor] Example code generated from XML or XSD files failed to compile
  • 10.5.8.10. Micro Application Generator
    • 10.5.8.10.1. [Major] NullPointerException when using -outputFinalQoS if QoS Profile did not define each internal QoS
    • 10.5.8.10.2. [Minor] MAG failed to generate code when qos_profile inherited from individual QoS policies
    • 10.5.8.10.3. [Minor] MAG always used default value for disable_auto_interface_config
    • 10.5.8.10.4. [Minor] MAG failed if arguments contained whitespace on Linux systems
    • 10.5.8.10.5. [Trivial] XSD validation failed if flags used a combination of values
  • 10.5.8.11. OMG Specification Compliance
    • 10.5.8.11.1. [Major] DDS_StatusCondition_set_enabled_statuses did not trigger if an active condition was enabled and had incorrect default value
  • 10.5.8.12. Interoperability
    • 10.5.8.12.1. [Critical] Failure to deserialize fragmented samples sent by Connext Professional 7
    • 10.5.8.12.2. [Critical] Inline QoS offset non-compliant with DDSI-RTPS standard
    • 10.5.8.12.3. [Critical] Connext Micro may have repeated requesting a sample that was no longer available from a DataWriter
    • 10.5.8.12.4. [Critical] Failure to deserialize a fragmented sample with multiple fragments in a DATA_FRAG submessage
  • 10.5.8.13. Vulnerabilities
    • 10.5.8.13.1. [Critical] Vulnerabilities in RTI Micro Application Generator (MAG)
    • 10.5.8.13.2. [Critical] Illegal memory access when failing to generate interpreter programs
    • 10.5.8.13.3. [Critical] Potential crash when receiving a malformed sample using DDS_XCDR2_DATA_REPRESENTATION
  • 10.5.8.14. Other
    • 10.5.8.14.1. [Minor] Delay in sending data when using a flow-controller
    • 10.5.8.14.2. [Minor] Non-default timer resolutions may have caused an incorrect timeout
