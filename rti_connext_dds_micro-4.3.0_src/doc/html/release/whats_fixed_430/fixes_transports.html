10.4.3. Transports¶

10.4.3.1. [Major] Zero Copy v1 limited the total number of shared memory segments to 500¶

When using the Zero Copy v1 transport, the total number of shared memory segments per DomainParticipant was incorrectly limited to 500.

[RTI Issue ID MICRO-3489]

10.4.3.2. [Trivial] UDP registration documented incorrectly¶

The Connext Micro documentation stated incorrectly that the UDP transport was automatically registered.

[RTI Issue ID MICRO-11445]

10.4.3.3. [Trivial] Internal UDP pings failed to send¶

Internal UDP pings failed to send, which would cause Connext Micro to log the following warning on startup:

WARNING: ModuleID=4 Errcode=235

[RTI Issue ID MICRO-8929]
